# To-Do List Application

## Project Link:
Check out the live version of the project here:
[To-Do List Live Demo](https://dharan-sdc.github.io/JS-todo/)

## Description:
This project is a dynamic and interactive To-Do List application built using HTML, CSS, and JavaScript. The app allows users to easily add, delete, and manage their tasks. Additional features include marking tasks as completed, editing tasks, and storing tasks in the browser's local storage to ensure they persist even after the page is reloaded.

## Key Features:
- **Add New Tasks:** Users can add new tasks to the to-do list using an input field.
- **Mark Tasks as Complete:** Users can click on tasks to mark them as complete, visually distinguishing completed tasks from pending ones.
- **Edit Tasks:** Users have the ability to edit existing tasks.
- **Delete Tasks:** Users can delete tasks from the list.
- **Persistence:** Tasks are saved in the browser's local storage, so they remain even after refreshing the page.

## Technologies Used:
- **HTML:** Used for the structure of the application.
- **CSS:** Used for styling the application, making it visually appealing.
- **JavaScript:** Handles functionality, including adding, editing, deleting tasks, and storing tasks in local storage.

## How to Use:
1. Clone or download the repository to your local machine.
2. Open `index.html` in your browser to run the app.
3. Use the input field to add new tasks.
4. Click on a task to mark it as completed.
5. Edit or delete tasks as needed.
6. Refresh the page, and your tasks will persist due to local storage.

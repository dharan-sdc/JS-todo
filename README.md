Project Title: To-Do List using Javascript

Project link https://dharan-sdc.github.io/JS-todo/

Description: This project involves building a dynamic and interactive to-do list application using HTML, CSS, and JavaScript. The application will allow users to add, delete, and manage their tasks efficiently. It can also include features like marking tasks as complete, editing tasks, and storing tasks locally so they persist across page reloads.

Key Features:

Add New Tasks: Users can add new tasks to their to-do list through an input field.

Mark Tasks as Complete: Users can click on a task to mark it as completed, which will visually differentiate completed tasks from pending ones.

Edit Tasks: Users can edit existing tasks.

Delete Tasks: Users can remove tasks from the list.

Persistence: Tasks are stored in the browser's local storage, ensuring they remain even after the page is refreshed.

Technologies Used:

HTML: For the structure of the application.

CSS: For styling the application and making it visually appealing.

JavaScript: For the functionality, including adding, editing, deleting tasks, and saving them to local storage.
